# ---------------------------------------------------------------------------
# 说明
#
# 1. 勾选「排除」的应用走直连, 其余走 WARP。若想反过来(只有少数应用走 WARP),
#    部分版本支持 Include 模式, 在 Split Tunnels 里切换。
#
# 2. 银行/支付类 App 建议一律排除: 走境外出口容易触发风控或验证码。
#
# 3. Android Auto、无线投屏、局域网设备(NAS/摄像头/打印机)相关 App 建议排除,
#    否则会连不上 —— 这是社区反馈最多的问题。
#
# 4. 包名会随版本变化, 以手机上「设置 → 应用管理」里显示的为准。
#
# 5. 新版 One Agent App 可能没有「排除应用」入口(Cloudflare 2025 年调整),
#    此时只能用「排除路由(Manage excluded routes)」按 IP 段分流。
# ---------------------------------------------------------------------------
