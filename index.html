运行日志

需以管理员身份运行（run.bat 会自动提权）。规则库来自 APNIC 中国大陆 IPv4 分配，定期点「更新中国IP列表」可保持最新。
如遇异常，随时点「一键还原」即可回到干净网络状态。本工具仅依赖 Python 标准库，托盘图标使用系统 API 实现。
